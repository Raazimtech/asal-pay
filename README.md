Responsive digital-wallet MVP built with HTML, CSS and vanilla JavaScript.

## Features
- Login and account creation
- Wallet balance
- Send money confirmation flow
- Payment requests
- Demo top-up
- Transaction history
- Profile and wallet ID
- PWA manifest
- Mobile-first UI
- LocalStorage persistence

## Production integration
This browser MVP does not move real money by itself. Real transfers require the client's payment-provider API plus a secure backend/edge function, authentication, webhooks, idempotency, reconciliation and fraud controls. Provider secrets must never be placed in frontend JavaScript.
